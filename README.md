# 企业通用办公系统（OA 基础版）

一套**开箱即用**的通用版企业办公自动化（OA）系统，覆盖人事、行政、审批流与文件管理四大基础模块。**不含业务模块与客户管理**，结构简单、拿来即用，适合作为企业信息化的第一步。

> 在线展示页：**https://jiaxuan881114-gif.github.io/enterprise-oa-showcase/**（GitHub Pages 托管）

## 功能概览

| 模块 | 功能点 |
| --- | --- |
| 人事管理 | 员工档案（增改查 / 多条件筛选）、组织架构（部门 / 岗位）、考勤管理（出勤与请假记录） |
| 行政管理 | 公告通知（分级发布 / 归档）、固定资产（台账 / 状态统计）、会议室预约 |
| 审批中心 | 请假 / 报销 / 采购 / 用章等流程、发起 → 逐级审批 → 同意或驳回、我的申请 / 待我审批 / 全部审批 |
| 文件管理 | 文件上传、分类管理、下载与删除 |

权限体系：管理员与普通员工两种角色分离（管理员维护人事行政数据，员工发起审批与上传文件）。
